## C Language

Using C and the native APIs is not the only way to write programs, this gives you the best performance and smallest possible size of executable with no external libraries (only Win32 DLL are required)

## Visual Basic or Borland Delphi

These approach provide easy development experience with more focus on application logic rather than the low level stuff, to learn this approach use [Learn Visual Basic Now (1996), by Michael Halvorson.](https://archive.org/details/learnvisualbasic00halv)

## MFC with Microsoft Visual C++

This method allows use of C++ that have wrapped the Win32 API in classes and is relatively much easier [Book](https://assets.ctfassets.net/9pcn2syx7zns/6ejGpuR3LJdenVQWDCe23W/d152db4718309d396d07aa8b444a541e/mfc2.pdf) But this is also not the best option as it is difficult to find proper documentation about this.

## Java

Around year 2000 java was also a popular choice for GUI development for windows using J++. `Programming Visual J++ 6.0 (1999), by Stephen R. Davis` books gives good introduction about how to write windows program using J++
