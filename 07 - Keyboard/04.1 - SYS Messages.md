The `WM_SYSKEYDOWN` and `WM_SYSKEYUP` messages are usually generated for keys typed in combination with the `Alt key`. Programs usually ignore the `WM_SYSKEYUP` and `WM_SYSKEYDOWN` messages and pass them to [[03 - Window Procedure|Default Window Procedure]].

Almost everything that affects your program’s window passes through your window procedure first. Windows does something with the message only if you pass the message to [[03 - Window Procedure|DefWindowProc]]. For instance, if you add the lines

```c
case WM_SYSKEYDOWN:
case WM_SYSKEYUP:
case WM_SYSCHAR:
return 0 ;
```

to a window procedure, you effectively disable all Alt-key operations when your program’s
main window has the input focus. 

---

## WM_SYSCHAR 

`WM_SYSCHAR` is a Windows message (`0x0106`) posted to a window when a character key is pressed while the **ALT key is held down** (system character) or when a menu key (`F10`) is pressed.

It signifies a system-level command rather than text input, requiring it to be passed to `DefWindowProc`.

Simply this message is passed when some character key is pressed when system keys like `Alt` or `F10` are held down.
