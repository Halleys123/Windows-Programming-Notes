This is a message that is generated when the Window is resized, which is then followed by another message [[01.2 - WM_PAINT|WM_PAINT]].

>[!important]
>WM_PAINT message is only sent if the class style is defined with CS_HREDRAW and/or CS_VREDRAW

## WPARAM and LPARAM values

### wParam

The type of resizing that is done, as a window could be maximized, minimized, restored etc.

| Value                       | Meaning                                                                                               |
| --------------------------- | ----------------------------------------------------------------------------------------------------- |
| **SIZE_MAXHIDE**<br><br>4   | Message is sent to all pop-up windows when some other window is maximized.                            |
| **SIZE_MAXIMIZED**<br><br>2 | The window has been maximized.                                                                        |
| **SIZE_MAXSHOW**<br><br>3   | Message is sent to all pop-up windows when some other window has been restored to its former size.    |
| **SIZE_MINIMIZED**<br><br>1 | The window has been minimized.                                                                        |
| **SIZE_RESTORED**<br><br>0  | The window has been resized, but neither the **SIZE_MINIMIZED** nor **SIZE_MAXIMIZED** value applies. |
The low-order word of _wParam_ specifies the new width of the client area.
### lParam


The high-order word of _lParam_ specifies the new height of the client area.
