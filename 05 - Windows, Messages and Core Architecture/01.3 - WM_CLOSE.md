
This message is added to the queue when the close button is clicked or close is selected from window's menu or `alt + f4` is pressed. 

If you decide to catch this message in the [[03 - Window Procedure|window procedure]], it is your decision how to treat it, that means, you have the choice to either continue with the process of closing the window or totally ignore it.

If you decide to close the window you need to tell the OS to destroy the window now with the help of `DestroyWindow` function which will then ask OS to use [[01.4 - WM_DESTROY|WM_DESTROY]].

## Typical Handling of WM_CLOSE

```c
LRESULT CALLBACK WndProc(HWND hWnd, UINT msg, WPARAM wParam, LPARAM lParam) {
	switch (msg) {
		case WM_CLOSE:
			DestroyWindow(hWnd);
			break;	
	}
}
```
