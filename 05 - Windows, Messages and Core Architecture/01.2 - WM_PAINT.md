This is the second message that is inserted in the queue, it informs that program that a part of client area or whole client area is `invalid` or must be updated either due to a window creation, resize, closing, minimizing of window or manual invalidation by the user.

`Invalid` in above context holds a special meaning, by Invalid client area in windows programming, it is meant that program has not yet drawn anything on the window or the thing that were drawn are now not valid either due to resize or minimize.

To launch a WM_PAINT message when the window is resized you must set the [[02.1 - WNDCLASS Styles#^b2c598|CS_HREDRAW and CS_VREDRAW]] bits in [[02.1 - WNDCLASS Styles|WNDCLASS Styles]].

When you minimize HELLOWIN and then restore the window again to its previous size, Windows does not save the contents of the client area. Under a graphical environment, this would be too much data to retain. Instead, Windows invalidates the window

Another scenario in which window invalidates is if two windows overlap each other, then one of the window's sub-part must be invalidated.

## Handling WM_PAINT

Processing of WM_PAINT almost always begins with a `BeginPaint(hWnd, &ps)` function call, this returns a Handle to [[Device Context]] and ends with a `EndPaint(hWnd, &ps)`.

Both functions take the second parameter which is a PAINTSTRUCT, it contains some information that a window procedure can use for painting the client area.

### `BeginPaint` Function

During the BeginPaint call, Windows erases the background of the client area if it hasn’t been erased already, it is erased with the brush that is specified in the [[02 - Window Class#^efdbd9|hbrBackground]] field of the [[02 - Window Class|WNDCLASS]].
Then this function validates the client area and returns a "Handle to [[Device Context]]", This handle that is returned **by BeginPaint** won't allow you to write/draw anything outside the client area.

### EndPaint

This function releases the [[#Device Context]] that means you can't use this handle of device context to draw on client area.

## Device Context

Device context refers to a physical output device such as video display and its device driver. 
A device context is required to display text, graphics in the client area of the window.
